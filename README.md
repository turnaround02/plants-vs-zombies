# 🌻 植物大战僵尸 - 塔防游戏

一个使用 HTML5 Canvas 构建的植物大战僵尸塔防游戏。僵尸从右侧进攻，玩家放置植物进行防守。

## 🎮 游戏特性

- **6 种植物**：向日葵、豌豆射手、寒冰射手、坚果墙、樱桃炸弹、双发豌豆
- **3 种僵尸**：普通僵尸、路障僵尸、奔跑僵尸
- **5 波进攻**：第一关完整流程
- **阳光经济系统**：天空掉阳光 + 向日葵生产阳光
- **植物冷却系统**：放置后需要等待冷却
- **音效系统**：Web Audio API 生成，无需外部音频文件

## 🚀 运行方式

### 方式一：直接打开浏览器

直接双击 `index.html` 即可在浏览器中运行。

### 方式二：本地 HTTP 服务器

```bash
# Python
python -m http.server 8080
# 然后访问 http://localhost:8080

# Node.js
npx serve .
```

### 方式三：Docker

```bash
docker-compose up -d
# 然后访问 http://localhost:8080
```

## 🎯 游戏玩法

1. 点击「开始游戏」进入第一关
2. 点击植物卡片选择植物（需要足够的阳光）
3. 点击草地格子放置植物
4. 点击收集掉落的阳光
5. 阻止僵尸到达左侧房屋！

## 🧪 自动化测试

项目包含 Puppeteer 无头浏览器测试脚本，可自动截图并检查游戏状态：

```bash
npm install
node test/headless-test.js
```

测试脚本会：
1. 启动本地服务器
2. 打开游戏并截图主菜单
3. 点击开始游戏，放置植物，截图游戏画面
4. 检查游戏状态与逻辑
