# 夜间关卡（第 9 关）设计文档

> **日期：** 2026-09-20
> **状态：** 已确认
> **范围：** 浏览器版（Godot 版冻结，不同步）

## 1. 背景与目标

当前浏览器版已具备 11 植物 / 6 僵尸 / 8 关卡 / 得分 / 存档 / 检查点 / 割草机 / 铲子，测试 12/12 全绿。为增加玩法深度，引入首个环境机制——**夜间关卡**。

**目标：** 新增第 9 关为夜间关卡，整关无自然阳光（天空不掉阳光），开局送一笔阳光，深色背景 + 星空视觉，复用现有系统（得分/存档/检查点/割草机/铲子），蘑菇植物不加成。

## 2. 设计决策（来自 grilling 共识）

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 主攻方向 | 玩法深度（夜间关卡） | 机制深度比内容数量更能提升可玩性 |
| 双版本策略 | 聚焦浏览器版，Godot 冻结 | 浏览器版有完整 E2E 测试，迭代最快 |
| 具体机制 | 夜间关卡 | 实现成本最低，与蘑菇植物天然配合 |
| 落地方式 | 新增第 9 关 | 不破坏已通关玩家进度 |
| 作用范围 | 整关生效（关卡级标志） | 实现最简单，符合小步快改 |
| 资源规则 | 无自然阳光 + 开局送 150 阳光 | 完全无阳光开局太卡，送一笔节奏最合理 |
| 卡组 | 保持默认卡组 | 当前无选卡界面，蘑菇植物已在卡组中 |
| 视觉 | 深色背景 + 星空 | 纯 Canvas 绘制，成本低，区分明显 |
| 蘑菇联动 | 不加成 | 保持机制简单，"无自然阳光"已足够逼玩家用蘑菇 |
| 割草机 | 保留 | 复用现有系统 |
| 测试 | 核心逻辑（资源 + 解锁） | 视觉测试脆弱易碎 |
| 交付 | master 直改，2 个 commit（实现 + 测试） | 改动小（<300 行） |
| 验收 | 功能 + npm test 全绿 + 手动浏览器验证 | 沿用上次 mower+shovel 标准 |

## 3. 需求规格

### 3.1 关卡定义（`js/config.js`）

新增 `LEVELS[9]`，包含：
- `id: 9`
- `name: '第九关：夜幕降临'`
- `startSun: 150`（开局送 150 阳光）
- `night: true`（夜间标志，整关生效）
- `waves`：3 波，难度略高于第 8 关（引入 bucket/poleVault/newspaper 混合，数量略增）

### 3.2 夜间资源规则（`js/game.js`）

- 当 `level.night === true` 时，`update(dt)` 中**跳过天空掉阳光**逻辑（`sunFallTimer` 不累积、不生成 `source:'sky'` 的阳光）。
- 开局阳光由 `level.startSun` 决定（第 9 关为 150），无需额外逻辑。
- 植物生产的阳光（向日葵 `sunProducer`）不受影响，照常工作。

### 3.3 夜间视觉（`js/game.js`）

- `renderBackground(ctx)` 检测当前关卡 `night` 标志：
  - 夜间：草地渐变改为深色（如 `#1a237e` → `#0d1b2a`），天空区域改为深蓝（`#0b1026`），并绘制星空（随机小点 + 少量闪烁）。
  - 白天：保持现有逻辑不变。
- 房屋、网格、植物、僵尸、子弹等绘制逻辑不变。

### 3.4 复用现有系统

- 得分 / 存档 / 检查点 / 割草机 / 铲子：全部照常工作，无额外改动。
- 检查点保存逻辑（`level.js` 中段保存）自动适用于第 9 关。
- 通关后 `SaveStore.addClearScore` 自动解锁第 10 关（若存在）或封顶。

### 3.5 蘑菇不加成

- 蘑菇植物（蘑菇射手/爆炸菇/魅惑菇）在夜间与白天表现完全一致，无任何加成。

## 4. 文件改动清单

| 文件 | 改动 |
|------|------|
| `js/config.js` | 新增 `LEVELS[9]`（含 `night:true`） |
| `js/game.js` | `update()` 跳过夜间天空掉阳光；`renderBackground()` 支持夜间深色背景 + 星空 |
| `test/headless-test.js` | 新增测试 13：夜间关卡核心逻辑 |

## 5. 测试规格

新增测试 13（夜间关卡核心逻辑），断言：
1. 第 9 关 `night === true`。
2. 进入第 9 关后开局阳光为 150。
3. 夜间关卡在 `SUN_FALL_INTERVAL` 时间内**不生成** `source:'sky'` 的阳光（`game.suns` 中无 sky 来源）。
4. 通关第 9 关后 `SaveStore` 解锁状态正确（`unlockedLevel >= 9`）。

## 6. 非目标（YAGNI）

- 不做夜间蘑菇加成。
- 不做选卡界面。
- 不做分波次环境切换。
- 不同步 Godot 版。
- 不做视觉测试（背景色/星空断言）。

## 7. 验收标准

1. `npm test` 全绿（含新增测试 13）。
2. 手动浏览器验证：进入第 9 关，背景为深色 + 星空，天空不掉阳光，开局 150 阳光，向日葵/蘑菇可正常生产阳光，通关后解锁状态正确。
3. 无控制台错误。
