# Godot 全功能同步设计文档

> **日期：** 2026-09-20
> **状态：** 已确认
> **范围：** Godot 版（`godot_project/`），浏览器版冻结（已具备全部功能，测试 13/13 全绿）

## 1. 背景与目标

浏览器版已具备 11 植物 / 6 僵尸 / 9 关卡（含夜间第 9 关）/ 得分 / 存档 / 检查点 / 割草机（小推车）/ 铲子 / 暂停 / 魅惑菇 / 关卡选择。Godot 版目前只对齐到"8 关卡 + 11 植物 + 6 僵尸数据 + 得分 + 简单存档"，存在以下缺口：

- **行为断裂**：魅惑菇静默失效（`Plant.gd` 调用 `set_charmed`/`charm`，但 `Zombie.gd` 两者均未定义）；`_get_target_zombie` 取行内第一只僵尸而非最近（截断 bug）；撑杆跳跃、读报加速仅存数据无行为
- **机制缺失**：小推车、铲子、暂停、检查点、关卡选择 UI、夜间关卡与视觉
- **流程差异**：胜利后自动推进下一关（浏览器版为结算画面 + 手动进入）

**目标：** 一次性把浏览器版全部功能同步到 Godot 版，使两版行为对齐。

## 2. 设计决策（来自 grilling 共识）

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 同步范围 | 浏览器全部功能（夜间9关/小推车/铲子/检查点/暂停/关卡选择/魅惑修复/行为缺口） | 两版对齐是唯一可维护状态 |
| 魅惑修复 | 在 `Zombie.gd` 补 `is_ally` + `set_charmed()` | 根因修复：调用方已按此接口编写，行为对齐浏览器 `zombie.isAlly=true` 右转打普通僵尸 |
| 目标选择 | 修 `_get_target_zombie` 取本行距离最近的活僵尸 | 与浏览器 `getFirstZombieInRow` 语义对齐 |
| 撑杆/读报 | 实现 `jump_over_plant` 越障跳跃 + `newspaper_behavior` 首次被击加速（`speed_after_hit`） | 数据已在 `ZombieTypes.gd`，仅补行为 |
| 小推车 | 每行一次性保险：僵尸到达该行最左时触发，清除本行全部僵尸，本行小推车消耗 | 对齐浏览器 mower 语义 |
| 铲子 | HUD 按钮进入铲子模式，点击植物铲除并回收 50% 阳光 | 对齐浏览器 `shovelMode/removePlant` |
| 暂停 | 键盘（Esc/P）+ HUD 按钮双入口，`isPaused` 独立于关卡状态机 | 与浏览器版解耦方式一致 |
| 检查点 | 基础版：每关中段（半波次）自动快照 `waveIndex/sun/plants/zombies`，失败后可从检查点恢复 | 对齐浏览器 `SaveStore` 中段保存语义 |
| 关卡选择 UI | 主界面/结算界面提供关卡列表，已解锁可选、未解锁置灰 | 对齐浏览器 `levelSelectBtn/#level-select` |
| 胜利流程 | 停止自动推进，改为结算画面（得分/奖励）+ "进入下一关"按钮 | 与关卡选择 UI 一致，手动掌控节奏 |
| 夜间视觉 | 简单版：深色背景 + 静态星空点缀（不复制浏览器渐变闪烁动画） | 控制工作量，差异可感知即可 |
| 夜间第 9 关 | 完整照搬浏览器 `LEVELS[9]`（`night:true`、`startSun:150`、3 波），延迟毫秒 → 秒换算 | 内容一致 |
| 夜间资源规则 | `night` 关不生成天空阳光，开局阳光由 `start_sun` 决定 | 与浏览器一致 |
| 执行方式 | master 直改，按功能拆 commit；先 spec 后 plan 再执行 | 仓库现态如此 |
| 验证 | 手动 Godot 运行验证（无 Godot 测试框架），浏览器版回归 13/13 不受影响 | 成本约束 |

## 3. 需求规格

### 3.1 数据层

- **`Levels.gd`**：新增第 9 关（`night: true`、`start_sun: 150`、3 波，内容照搬浏览器 `LEVELS[9]`；`delay` 由毫秒换算为秒）。关卡延迟单位全程为秒（现有约定），换算规则：`delay_seconds = delay_ms / 1000`。
- **`ZombieTypes.gd`**：数据已齐全（`jump_over_plant`、`newspaper_behavior`、`speed_after_hit`），本项仅确认无需改动。

### 3.2 僵尸行为（`Zombie.gd`）

- **魅惑（charm）**：新增 `is_ally: bool` 与 `set_charmed(ally: bool)`。魅惑后：
  - 行走方向反转（向右），不再扣血前进
  - 不再攻击植物；改为攻击同侧普通（非魅惑）僵尸
  - 走到最右出界即移除
- **撑杆跳跃**：`jump_over_plant` 僵尸接近第一株植物时执行一次跳跃动作（短暂加速/越过），之后按普通速度行进。
- **读报加速**：`newspaper_behavior` 僵尸首次被命中后丢弃报纸，速度切换为 `speed_after_hit`（30），且此后不再回落到原速。

### 3.3 植物行为（`Plant.gd` / `Projectile.gd`）

- **`_get_target_zombie`**：改为取本行 `distance_to(position)` 最近（且在射程内、未死）的僵尸。
- **魅惑调用链**：`_do_charm` 命中后调用 `z.set_charmed(true)`（修复后真实生效）；`charm` 分支保留兼容。
- 弹道（`Projectile.gd`）慢速/穿透/魅惑标志暂不实现（浏览器版当前关卡未使用该类弹道机制，YAGNI）。

### 3.4 小推车（mower）

- 每行一个一次性小推车，初始位于该行最左侧。
- 任一僵尸到达该行最左（`x <= 0`）时：若小推车可用 → 立即清除本行全部僵尸（得分计入），小推车消耗；若不可用 → 走现有失败流程（`zombie_reached`）。
- 替换现有"僵尸到达 x<=0 直接失败"的路径。

### 3.5 铲子（shovel）

- HUD 增加铲子按钮；点击后进入铲子模式（再次点击或取消键退出）。
- 铲子模式下点击/选中一株植物：铲除之，回收其阳光成本的 50%。
- 与暂停互不影响。

### 3.6 暂停

- 键盘 Esc / P 与 HUD 暂停按钮均可切换 `isPaused`。
- 暂停期间所有实体 `_process` 停止推进（`get_tree().paused` 或 Main 侧统一门控），HUD 可操作（可恢复、可打开关卡选择）。
- `isPaused` 独立于 `wave_state` 状态机。

### 3.7 检查点存档

- 每关第 `ceil(total_waves/2)` 波开始时自动保存快照：`waveIndex / sun / plants(type,grid位置) / zombies(type,位置,hp)`。
- 关卡失败（小推车耗尽后僵尸达家）时提供"从检查点恢复"入口；无检查点则走原失败流程。
- 与现有 `_save_progress`（`unlocked_level/total_score/wins`）并存，检查点独立存储。

### 3.8 关卡选择 UI 与胜利流程

- 主菜单与胜利结算画面均可进入关卡选择面板：已解锁关卡可选，未解锁置灰。
- `_on_level_won` 不再自动推进：停止波次、显示结算（本关得分 + 奖励 `500 + sun/10`），提供"进入下一关"按钮（最后一关则显示通关文案 + 返回菜单）。
- 选择已解锁关卡可从头开始该关。

### 3.9 夜间视觉

- `night` 关卡：战场背景切换为深色（深色渐变底色 + 若干静态白色星点），天空区深蓝。
- 非夜间关卡保持现状。

## 5. 验证规格

- Godot 手动验证清单：
  1. 第 9 关进入后开局阳光 150，无天空阳光掉落，深色星空背景
  2. 魅惑菇接触僵尸后该僵尸右转并攻击普通僵尸
  3. 豌豆射手在同行多僵尸时命中最近者
  4. 撑杆僵尸越障跳跃；读报僵尸首次被击后加速
  5. 僵尸到达最左触发该行小推车清行；小推车用尽后走失败流程
  6. 铲子模式铲除植物回收 50% 阳光
  7. Esc/P 与按钮均可暂停/恢复；暂停时实体静止
  8. 中段波次自动存档；失败后可从检查点恢复
  9. 关卡选择面板解锁状态正确；胜利结算后手动进入下一关
- 回归：浏览器版 `npm test` 13/13 不受本次改动影响（浏览器文件零改动）。
